# 常见工作流教程

这些教程覆盖最常见的端到端任务。完成每个任务后都要检查“成功标志”，不要只看某个命令退出码。

<!-- section:s002 -->
## 教程一：切换到另一台已配对电脑

**起点：** 两台电脑都曾与不同槽位配对。

1. 在手柄上进入 `Settings > BLE Hosts`。
2. 选择目标电脑对应的 `SAVED` 槽位。
3. 打开目标电脑蓝牙，等待 `WAIT → LINK`。
4. 在纯文本框测试宏键。

**成功标志：** 小屏显示 `LINK`，目标电脑收到宏输入。仅在电脑端点击“断开”不等于切换手柄槽位。

<!-- section:s003 -->
## 教程二：添加一台新电脑

1. 选择一个 `EMPTY` 槽位。
2. 确认小屏显示 `PAIR`。
3. 在 120 秒内从系统蓝牙添加完整的 `CommunistKB-XXXX`。
4. 等待 `LINK` 并测试输入。

**成功标志：** 新槽位变为已保存状态，重新开机后能通过该槽位重连。三个槽位已满时，只删除确认不再使用的槽位。

<!-- section:s004 -->
## 教程三：让 Agent 状态显示到手柄

1. 启动 AutoClipboard 并确认设备连接。
2. 按 [Agent 状态配置指南](../agent-signal-setup.md) 安装当前客户端的 Hook。
3. 启动一个短任务，触发 working、approval、done 或 blocked 状态。
4. 对比 Dashboard、小屏和灯环。

**成功标志：** 三个界面的状态语义一致。若状态失败但宏键正常，不要重配蓝牙。

<!-- section:s005 -->
## 教程四：安全升级 AutoClipboard

1. 从官网的准确版本化链接下载安装包。
2. 核对 Release 文件名、大小和 SHA-256。
3. 记录 Profile、快开目标和关键设置。
4. 正常退出应用并运行安装程序。
5. 首次启动后检查设置是否保留，再测试宏、设备连接和 Agent Hook。

**成功标志：** 版本更新，用户配置未丢失，Hook 指向新安装路径。若安装异常，使用升级前设置快照恢复。

<!-- section:s006 -->
## 教程五：区分 HID、软件连接和串口

| 现象 | 最可能的链路 | 第一步 |
| --- | --- | --- |
| 宏键不能输入 | HID 蓝牙 | 看 `LINK`、当前 Profile 和纯文本测试 |
| 宏键正常，软件显示未连接 | 应用 GATT | 保持手柄唤醒并重启应用连接 |
| 固件维护找不到端口 | USB 串口 | 检查数据线、设备管理器和 CH343 |
| Agent 状态不变化 | Hook/Activity | 刷新 Hook 并检查 Dashboard |

**成功标志：** 只修复失败的链路，不破坏已经正常的链路。

<!-- section:s007 -->
## 教程六：准备 V3 固件更新

1. 确认任务确实需要固件更新，而不是软件或配对问题。
2. 选择用户明确打开的串口，不自动猜测端口。
3. 读取板型、设备序列号和当前版本。
4. 校验 V3 包的版本、大小、SHA-256 和内部布局。
5. 普通更新只执行 validated app-only 写入应用区。
6. 写入后重新读取身份和版本，并完成串口及 BLE/IMU smoke。

**成功标志：** 写入目标是唯一 V3，版本读回正确，NVS、bonds 和 SPIFFS 保留。首次初始化、恢复和 full flash 是独立流程，不能自动套用本教程。
