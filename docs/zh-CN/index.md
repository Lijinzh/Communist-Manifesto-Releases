## 事实来源与版本边界

- 官网负责产品入口、下载导航和面向新用户的短路径说明。
- 本文档树负责完整、可版本管理的中英文说明。
- GitHub Release 是正式构建和主发布源，Gitee 是中国大陆备用源。
- `latest.json` 是自动更新角色、下载地址、文件大小和 SHA-256 的机器可读来源。
- 阶段发布可能先提供部分平台；未发布的平台不会用占位文件代替。
- D4 已停止维护；当前开发、验证和新固件发布只面向 V3。
