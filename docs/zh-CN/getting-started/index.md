# Getting Started

这一板块帮助你从“刚拿到手柄”走到“已经验证基本输入和软件连接”。整个流程优先使用可逆、低风险操作；第一次使用不需要更新固件或清除配对。

<!-- section:s002 -->
## 推荐入口

- [5 分钟快速开始](quickstart.md)：完成安装、供电、蓝牙配对和首次宏键测试。
- [完整使用说明书](../user-guide.md)：需要图片、菜单细节和多主机说明时继续阅读。
- [AI Coding Handle Skill 安装](../user-guide.md#2-安装并使用-ai-coding-handle-skill)：让兼容的 AI Agent 帮你完成安装和诊断。

<!-- section:s003 -->
## 开始前准备

1. 一台 Windows、Ubuntu/Linux 或 macOS 电脑。
2. 一只 V3 字库手柄和足够电量。
3. 需要串口诊断时准备支持数据传输的 USB Type-C 线；日常蓝牙使用只需供电和系统蓝牙。
4. 从官网或正式 Release 下载与你的平台匹配的安装包。

<!-- section:s004 -->
## 首次验收标准

完成快速开始后，应同时确认：

- 系统蓝牙中存在完整的 `CommunistKB-XXXX` 设备名。
- 手柄小屏从 `PAIR` 或 `WAIT` 进入 `LINK`。
- 在纯文本编辑器中，至少一个宏键能产生预期输入。
- 启动 AutoClipboard 后，界面能正常打开且没有安装损坏提示。
- 只有需要设备设置、状态、IMU 或 Agent 功能时，才继续验证软件 GATT 连接。
