# AutoClipboard v0.3.68 Windows / Linux 正式发布

状态：Windows x64、Linux amd64 与 V3 `0.3.68` 固件正式发布；macOS 后续补充。

- 源码标签：`v0.3.68`
- 桌面源码提交：`bb0ebababb70a16660b5f13dce5335df01b7c314`
- 固件源码提交：`88f55b4b05d7bc6af4af2a5fc1c1ddf23cf03057`
- 组件版本：AutoClipboard `0.3.68`、Skill `0.3.68`、V3 固件 `0.3.68`
- 构建方式：Windows 本机原生构建，Linux 专用节点原生构建；两端均绑定同一完整提交

<!-- section:s002 -->
## 主要更新

- 发布账户中心、桌面登录会话、像素主题背景与凸台风格界面、高级语音网关链路以及软件自动更新修复。
- Windows 与 Linux 安装包均通过各自完整 PyInstaller、包内 Maintenance、esptool runtime 和 GUI smoke 门禁。
- V3 普通模式使用 160 MHz、104/100/20 Hz 和约 15～22.5 ms BLE 连接；Halo/游戏模式临时升到 240 MHz、208/200/50 Hz 和约 7.5～15 ms。
- BLE 发射功率调整为 `+6 dBm`；新出厂默认 LCD `150/255`、灯环 `56/255`、2 分钟熄屏、30 分钟 Deep Sleep，升级迁移保留用户自定义值。
- Linux 构建脚本固定为 LF，避免 Git 归档或 Windows 检出把 `pipefail` 破坏为 `pipefail\r`。

## 自动更新与公开发布验收

- Windows 已从已安装的 `0.3.67` 客户端真实执行启动自动检查、公开 Release 下载与 SHA-256 校验、安装器启动、有序退出和 `0.3.68` 重启；注册表、运行进程及软件设置界面均确认 `0.3.68`。
- Windows 升级前后简体中文、经典主题、Agent 面板、强提醒、全局快捷键、关闭全局 Typeless 模式等关键设置保持。设置文件因应用正常保存而发生字节变化，因此本轮不把“字节级完全不变”列为已证明项。
- Linux 已确认机器当前安装 `0.3.67`，并由正式更新代码成功发现、下载和验证 `0.3.68` DEB 的版本、大小与 SHA-256。真实安装仍需要桌面用户 `lee` 在图形会话内确认 `pkexec`；专用 `buildbot` 账户无权代替该用户完成提权，所以本轮不把 Linux 自动安装写成通过。
- V3 固件在 Linux `/dev/ttyACM1`、`board=v3`、`sid=A1EA` 上从 `0.3.67` 更新到 `0.3.68`；只写 `0x10000` 应用区，写入哈希和版本回读通过。串口完整 smoke 通过；30 秒 BLE/IMU 收到 565 帧、18.83 Hz，无序号缺口、重复、看门狗超时或重置嫌疑。一次可选的 250 ms 状态轮询超时未中断 notify 流。
- GitHub 与 Gitee 最新 Release 均为 `v0.3.68`，五个附件名称与大小一致；Gitee 匿名 API 和每个附件下载地址均验证可读。
