# AutoClipboard v0.3.68 Windows / Linux 正式发布

状态：Windows x64 与 Linux amd64 正式发布；V3 固件沿用已验证的 `0.3.67` 包，macOS 后续补充。

- 源码标签：`v0.3.68`
- 最终源码提交：`bb0ebababb70a16660b5f13dce5335df01b7c314`
- 组件版本：AutoClipboard `0.3.68`、Skill `0.3.68`、V3 固件 `0.3.67`
- 构建方式：Windows 本机原生构建，Linux 专用节点原生构建；两端均绑定同一完整提交

<!-- section:s002 -->
## 主要更新

- 发布账户中心、桌面登录会话、像素主题背景与凸台风格界面、高级语音网关链路以及软件自动更新修复。
- Windows 与 Linux 安装包均通过各自完整 PyInstaller、包内 Maintenance、esptool runtime 和 GUI smoke 门禁。
- 发布器支持桌面增量版本原样携带已验证的历史 V3 固件，并在 `latest.json` 中保留各组件真实版本；不得重命名旧固件冒充桌面版本。
- Linux 构建脚本固定为 LF，避免 Git 归档或 Windows 检出把 `pipefail` 破坏为 `pipefail\r`。
