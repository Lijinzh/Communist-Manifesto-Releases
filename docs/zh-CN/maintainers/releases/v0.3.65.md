## 主要更新

- 增加跨平台语音输入基础设施、免费/高级两档界面、系统听写适配、受控云端网关客户端、账号登录和 Profile 基础；高级权益和生产网关仍以服务器端实际部署为准。
- 增加跟随系统主题的玻璃质感界面、首页和设备页 BLE 绿色/红色呼吸状态灯，并完善设备设置布局。
- 修复 Linux `Ctrl+Alt+字母` 快捷键录入，降低 Linux BLE 状态轮询压力。
- 提高 ESP32 BLE 发射功率，移除互相竞争的重连 owner，完善 macOS 已连接设备的 GATT 恢复与主机槽位引导。
- 强化 Linux、Windows 和 macOS 打包验证，确保 esptool `stub_flasher`、语音运行时资源、架构和敏感资源检查进入发布门禁。
- 增加 Codex 插件市场结构、Gitee 国内下载引导以及便携 Skill 安装支持。
