## 主要更新

- AutoClipboard 软件图标改为八颗环形排列的独立多彩 8-bit 像素灯珠，透明背景下保持严格八个可见对象，并在 Windows ICO 的 `16×16` 至 `256×256` 尺寸中保持可辨识。
- Windows 安装包完成完整 PyInstaller/Inno Setup 构建门禁，包含 esptool `targets/stub_flasher` 数据和对应运行时 smoke。
- 官网下载区同步展示新版软件图标并更新 Windows `0.3.67` 的 Gitee 优先、GitHub 备用直链；Linux 仍保留现有独立版本，不伪造 Windows 构建机未产出的 DEB。
- 本版本不恢复 D4 维护，也不改变 BLE UUID、设备名规则或 HID report descriptor。

## 本轮发布范围与后续

- 本轮正式附件固定为 Windows EXE、V3 固件 ZIP、Skill ZIP 和 `latest.json`。
- Linux DEB 由专用 Linux 构建机基于同版本后续构建和补充；当前自动更新元数据不声明 Linux。
- macOS 正式 DMG 由合作伙伴从相同源码基线编译、签名、公证并 stapling 后再补充；当前自动更新元数据不声明 macOS，不使用占位包或未公证预览包。
- D4 已停止维护，本版本不生成新的 D4 固件，自动更新元数据不声明 D4。
- GitHub 发布完成后立即运行 `git sync-release-mirrors` 同步 Gitee，并严格验证两边 `main`、全部标签、最新附件名称/大小以及 Gitee 匿名下载地址完全一致。
