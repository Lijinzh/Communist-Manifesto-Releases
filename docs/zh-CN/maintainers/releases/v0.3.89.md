# AutoClipboard v0.3.89 发布验收

AutoClipboard **0.3.89** / V3 固件 **0.3.71**

本版更新：

- 设备设置“电池与电源”新增“Agent 工作时允许深度睡眠”，默认开启，写入手柄并断电保留；关闭后 Agent 工作或交互提醒期间保持唤醒。
- 每次放入充电底座只播放一次提示音和约 4 秒大电池动画；满电停充和补充电不会反复提示，检测到拿起后重新允许下次提示。
- Agent 心跳、只读状态轮询和 IMU 推流不再阻止静置超时深睡，保留原睡眠时长及 IMU 触碰唤醒机制。
- Codex 等待回答时按待答题目数显示紫色灯环，普通文字回答后及时清理。
- Linux 在 Deskflow 把输入交给其他电脑时抑制本机语音快捷键，避免远程输入误触发；同步修正自动测试夹具。

Windows x64、Linux amd64、macOS Apple Silicon 安装包与 Skill 均从标签 `v0.3.89`、源码提交 `f45eb4bec69536c93b9e00d70153ac6e5b44ce35` 原生构建。V3 固件使用独立版本 `0.3.71`；D4 不再发布。

macOS 为 **Apple Silicon arm64、ad-hoc 签名、未经 Apple 公证的预览版**。复制到 `/Applications` 后执行 `xattr -cr /Applications/AutoClipboard.app`；未声称通过 Developer ID、公证、stapling、Gatekeeper 或 Intel 兼容验证。各附件大小与 SHA-256 见 `latest.json`。

功能源码已在 V3 实机完成 Agent 开关、重启保留与静置深睡验证，开发时版本标识为 `0.3.70`。本次重新构建的 `0.3.71` 包尚未执行版本回读；实际底座循环、满电补充电、动画实屏及电流测量仍待验证。
