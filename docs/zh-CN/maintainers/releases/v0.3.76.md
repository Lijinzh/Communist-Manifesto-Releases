# AutoClipboard v0.3.76 三平台发布

状态：Windows x64、Linux amd64、macOS Apple Silicon 未公证预览版和 AI Coding Handle Skill 发布；V3 固件继续使用 `0.3.68`。

- 源码标签：`v0.3.76`
- 桌面源码提交：`c15d0c11b47f738cfa8e03024af2e52abb41354e`
- 固件源码提交：`88f55b4b05d7bc6af4af2a5fc1c1ddf23cf03057`
- 组件版本：AutoClipboard `0.3.76`、Skill `0.3.76`、V3 固件 `0.3.68`

## 主要更新

- 高级语音加入多场景润色、个人热词、录音启动预缓冲，并修复 ASR 停止过程中和文字落框后的快捷键状态。
- 完善 Profile 专属手柄控制、Einstein 相对鼠标移动、Presenter 性能档状态保持和相关自动化 smoke。
- 桌面账户中心加入缓存快照和官网头像同步，隐藏内部账户标识并修复 macOS 回调处理。
- 设置与设备窗口改为独立非模态窗口，增加多套像素主题并修复 macOS 打包模型资源和 Linux 桌面入口。
- 固化 Windows、Linux、macOS 同提交原生构建、产物拉取、双端哈希和 GitHub/Gitee 镜像发布流程。

## macOS 未公证预览说明

- DMG 仅面向 Apple Silicon arm64，使用 ad-hoc 签名，未使用 Developer ID、Apple 公证或 stapling。
- 安装并拖入 `/Applications` 后执行 `xattr -cr /Applications/AutoClipboard.app`，再从“应用程序”打开。
- 该包不得声称通过 Gatekeeper 正式评估，也不得声称支持 Intel Mac。

<!-- section:s005 -->
## 验收边界

- 三个平台的安装包都由对应操作系统原生构建，并在 Windows 发布协调端重新计算 SHA-256；Linux 和 macOS 的远端哈希与下载后哈希完全一致。
- macOS 构建门禁验证了 packaged-source、包内 smoke、ad-hoc `codesign --verify`、arm64 主程序、DMG 挂载和安装说明；未执行 Developer ID、公证、stapling 或 `spctl` 正式门禁。
- 本轮没有修改或重新烧录 V3 固件，`0.3.68` 的历史 validated app-only、串口及 BLE/IMU physical-live 证据不扩展为本轮的新实机测试。
- 正式完成仍要求 GitHub 与 Gitee 最新 Release 的版本、附件名称和大小一致，并通过匿名 API 与附件下载验证。
