## 主要更新

- 将 AutoClipboard 原有听歌云朵图标替换为依据真实手柄照片重绘的像素风字库手柄，保留小屏、八枚橙色环形按键、四颗螺丝、四枚红色侧键、U 形握柄开孔和顶部圆形模块等识别特征。
- Windows 安装器使用精确发布包完成本机升级，确认应用版本为 `0.3.66`、升级前后设置 SHA-256 一致，且安装目录中的 PNG/ICO 与源码资产完全一致。
- 改进打包版 Alt 快捷键 smoke 的失败诊断输出，使捕获链路异常能明确显示具体未通过的检查项。
- 更新 V3 固件与 AI Coding Handle Skill 的 `0.3.66` 发布交接；本版本不恢复 D4 维护，也不改变 BLE UUID、设备名规则或 HID report descriptor。

- 本轮正式附件固定为 Windows EXE、V3 固件 ZIP、Skill ZIP 和 `latest.json`。
- Linux DEB 由专用 Linux 构建机基于同版本后续构建和补充；当前自动更新元数据不声明 Linux。
