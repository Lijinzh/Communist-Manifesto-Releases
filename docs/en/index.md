# ZKO Ziku Documentation Center

This is the canonical English documentation entry for the ZKO Ziku AI Coding Handle, the AutoClipboard desktop application, V3 firmware, and the AI Coding Handle Skill. The content is organized as a path from first setup to daily use, product concepts, task-oriented tutorials, development, and precise reference material.

> If you have just received the handle, start with [Getting Started](getting-started/index.md). If you are solving a specific problem, open [Guides and Tutorials](guides-and-tutorials/index.md) first, then consult [Reference](reference/index.md).

## Sources of truth and version boundaries

- The website provides product entry points, download navigation, and short first-use paths.
- This documentation tree provides complete, version-controlled English and Chinese guidance.
- GitHub Releases are the official build and primary publication source; Gitee is the mainland-China fallback.
- `latest.json` is the machine-readable source for update roles, URLs, sizes, and SHA-256 values.
- A phased release may contain only approved platforms; missing platforms are never replaced with placeholders.
- D4 is no longer maintained. Current development, validation, and new firmware releases target V3 only.
