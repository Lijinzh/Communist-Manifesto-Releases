## Quick glossary

| Term | Meaning |
| --- | --- |
| HID | Bluetooth keyboard input path visible to the operating system |
| GATT | BLE service path used by AutoClipboard for status, IMU, and device commands |
| Profile | A set of macro, display, lighting, and launch-target settings |
| Host slot | One Bluetooth host record stored on the handle; three exist |
| app-only | Firmware update that writes only the application region, not bootloader/partitions |
| `latest.json` | Metadata describing update roles, versions, URLs, sizes, and SHA-256 values |

<!-- section:s005 -->
## Reference update rules

Dynamic versions, download URLs, file sizes, and checksums must be verified against the current formal Release or `latest.json`, not copied from an old example. Hardware ports, device identity, and connection state must also be re-confirmed at operation time.
