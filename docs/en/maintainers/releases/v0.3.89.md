# AutoClipboard v0.3.89 release verification

AutoClipboard **0.3.89** / V3 firmware **0.3.71**

- Add a persistent device setting to allow deep sleep while Agent is active (enabled by default).
- Play one charging notification and a four-second large battery animation per docking session. Charge top-ups remain silent; picking up the handle rearms the next notification.
- Respect inactivity sleep during Agent heartbeats, read-only polling, and IMU streaming, with existing timeout and motion wake preserved.
- Show pending Codex questions using purple ring LEDs and clear them after ordinary text replies.
- Suppress Linux voice shortcuts while Deskflow owns remote input and update the matching test fixture.

The three native desktop packages and Skill share tag `v0.3.89` and source commit `f45eb4bec69536c93b9e00d70153ac6e5b44ce35`. V3 uses independent firmware version `0.3.71`; D4 is omitted.

The macOS download is an **Apple Silicon arm64, ad-hoc-signed, unnotarized preview**. Run `xattr -cr /Applications/AutoClipboard.app` after copying the app to `/Applications`. Developer ID, notarization, stapling, Gatekeeper approval, and Intel support are not claimed. Sizes and SHA-256 checksums are in `latest.json`.

Feature source passed physical V3 Agent sleep-setting, restart-persistence, and inactivity checks under development label `0.3.70`. The rebuilt `0.3.71` package has no physical version-readback claim. Dock cycling, full-charge top-ups, physical display inspection, and current measurements remain unverified.
