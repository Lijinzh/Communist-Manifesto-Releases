# AutoClipboard / ZKO firmware v0.3.65 phased formal release

Status: formal Windows, Linux, V3 firmware, and Skill release; macOS will be added later by a partner.

- Source commit: `88caff478679922819d234a86974abc33d2e880a`

## Highlights

- Added cross-platform voice-input foundations, free/premium tier UI, system-dictation adapters, a controlled cloud-gateway client, account login, and Profile foundations. Premium entitlement and the production gateway still depend on the actual backend deployment.
- Added system-theme glass styling, green/red breathing BLE indicators on the home and device pages, and refined device-settings layout.
- Fixed Linux `Ctrl+Alt+letter` shortcut capture and reduced Linux BLE status-polling pressure.
- Raised ESP32 BLE transmit power, removed competing reconnect owners, and improved macOS connected-device GATT recovery and host-slot guidance.
- Hardened Linux, Windows, and macOS packaging gates for esptool `stub_flasher`, voice-runtime resources, architecture checks, and sensitive-resource inspection.
- Added the Codex plugin marketplace layout, Gitee download guidance, and portable Skill installation support.
- Fixed AI Coding Handle Skill validation of official `releases/latest/download/...` installer URLs so generic agents such as Sol can download and verify the current Windows/Linux packages while still rejecting non-official repositories, non-HTTPS sources, filename mismatches, and checksum mismatches.
