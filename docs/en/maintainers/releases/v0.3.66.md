- The formal asset set for this phase is the Windows EXE, V3 firmware ZIP, Skill ZIP, and `latest.json`.
- A dedicated Linux builder will build and add the DEB for the same version later. The current update metadata does not declare Linux.
- A partner will add the formal macOS DMG after building it from the same source baseline with Developer ID signing, notarization, and stapling. The current update metadata does not declare macOS and must not use a placeholder or unnotarized preview.
