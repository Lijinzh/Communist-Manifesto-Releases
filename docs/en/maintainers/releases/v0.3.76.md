# AutoClipboard v0.3.76 three-platform release

Status: Windows x64, Linux amd64, an Apple Silicon macOS unnotarized preview, and the AI Coding Handle Skill are released; V3 continues to use firmware `0.3.68`.

- Source tag: `v0.3.76`
- Desktop source commit: `c15d0c11b47f738cfa8e03024af2e52abb41354e`
- Firmware source commit: `88f55b4b05d7bc6af4af2a5fc1c1ddf23cf03057`
- Component versions: AutoClipboard `0.3.76`, Skill `0.3.76`, V3 firmware `0.3.68`
- Build path: native local Windows, dedicated Linux, and dedicated Apple Silicon macOS builds, all bound to the same full desktop commit

<!-- section:s002 -->
## Highlights

- Added multi-scenario premium voice refinement, personal hotwords, and startup audio prebuffering, with fixes for stopping ASR and accepting the next shortcut after text insertion.
- Completed profile-specific handle controls, Einstein relative mouse movement, Presenter performance-mode state retention, and their automated smoke coverage.
- Added cached account snapshots and website avatar synchronization, hid internal account identifiers, and fixed macOS callback handling.
- Made settings and device windows independent non-modal dialogs, added more pixel themes, and fixed bundled macOS model resources and the Linux desktop entry.
- Standardized same-commit native Windows, Linux, and macOS builds, artifact collection, remote/local hashing, and GitHub/Gitee mirrored publication.

## macOS unnotarized preview notice

- The DMG targets Apple Silicon arm64 only, uses an ad-hoc signature, and has no Developer ID signature, Apple notarization, or stapling.
- After dragging it into `/Applications`, run `xattr -cr /Applications/AutoClipboard.app`, then open it from Applications.
- This package is not claimed to pass formal Gatekeeper assessment and is not claimed to support Intel Macs.

<!-- section:s005 -->
## Acceptance boundary

- Each installer was built natively on its target operating system and re-hashed by the Windows release coordinator; Linux and macOS remote hashes exactly match the collected files.
- The macOS gates covered packaged-source inspection, packaged smoke tests, ad-hoc `codesign --verify`, an arm64 main executable, DMG mounting, and the installation notice. Developer ID, notarization, stapling, and formal `spctl` gates were not run.
- This release did not change or reflash V3 firmware. The historical `0.3.68` validated app-only, serial, and BLE/IMU physical-live evidence is not presented as a new live test for this release.
- Completion still requires matching GitHub and Gitee latest-release versions, asset names, and sizes, plus anonymous API and attachment-download verification.
