# Getting Started

This area takes you from an unopened setup to verified basic input and a working desktop application. It prioritizes reversible, low-risk actions. First use does not require a firmware update or deleting Bluetooth bonds.

<!-- section:s002 -->
## Recommended entry points

- [Five-minute quickstart](quickstart.md): install, power on, pair, and test the first macro.
- [Complete user manual](../user-guide.md): continue here for images, menu details, and multi-host behavior.
- [AI Coding Handle Skill installation](../user-guide.md#2-install-and-use-the-ai-coding-handle-skill): let a compatible AI Agent assist with installation and diagnostics.

<!-- section:s003 -->
## What you need

1. A Windows, Ubuntu/Linux, or macOS computer.
2. A V3 ZKO handle with sufficient charge.
3. A data-capable USB Type-C cable only when serial diagnostics are needed; normal Bluetooth use needs power and system Bluetooth.
4. The platform-matching installer from the official website or formal Release.

<!-- section:s004 -->
## First-use acceptance criteria

After the quickstart, verify all of the following:

- The system Bluetooth list contains the complete `CommunistKB-XXXX` name.
- The handle display transitions from `PAIR` or `WAIT` to `LINK`.
- At least one macro produces the expected input in a plain-text editor.
- AutoClipboard opens without an installation-corruption warning.
- Validate the application GATT connection only when you need device settings, status, IMU, or Agent features.
